# Moss & Stone — Foundry VTT System

A community-built Foundry VTT system for **Moss & Stone**, a tabletop roleplaying game built on the **EZD6** rules engine.

## Current release

**v1.0.0**

This release includes character sheets, path and species automation, Predator Rolls, Supplies and Safe Zones, Poison, Whisper Stones, Sammiches, Tinker Tools, path-specific helpers, combat automation, and Dice So Nice compatibility.

## Installation

Download the latest release ZIP and extract the `moss-and-stone` folder into your Foundry VTT `Data/systems/` directory, then restart Foundry.

The folder structure should look like:

```text
Data/
  systems/
    moss-and-stone/
      system.json
      scripts/
      styles/
      templates/
      assets/
```

## Compatibility

- Foundry VTT minimum: v12
- Verified: v13
- Optional Dice So Nice integration is supported.
